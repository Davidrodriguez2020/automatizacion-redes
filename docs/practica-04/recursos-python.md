# Regristro de recursos de python

*Preguntas*
**1.	¿Qué es la documentación oficial de un lenguaje de programación?**
A. Son los materiales que los creadores de los lenguajes suelen usanr como guias, tutoriales, refrencias o ejemplos para explicar el como se usa su lenguaje de programación.

**2.	¿Qué información puede encontrarse en ella?**
A.Depende de cada recurso, pero en general se puede conseguir informacion, herramientas y materiales que nos ayuden a aprender mas sobre el lenguaje, resolvieron problemas o dudas y a desarrollar proyectos.

**3.	¿Cómo puede ayudar a resolver dudas sobre variables, listas, diccionarios, ciclos y funciones?**
A.Cuenta con documentacion, tutoriales, ejemplos de codigo y ejercicios practicos que explican el funcionamiento de los elementos y el como utilizarlos, corregir errores, etc.

**4.	¿Qué diferencia existe entre consultar documentación oficial y utilizar una respuesta publicada en un foro?**
A.En la documentacion oficial se obtiene infomracion documentada y mantenida por el resposable de el lenguaje mientras que en los foros se tienen respuestas que son para soluciones practicas a problemas especificos, consultado a otros ejemplos/formas de resolver el problema de otro programadores.
