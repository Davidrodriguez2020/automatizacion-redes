# Investigacion de recursos de GNS3 y automatización de redes

----------------

**1.	¿Qué tipo de problema podrías resolver consultando la documentación de GNS3?**
A.Con la documentacion de GNS3 podemos resolver problemas con la administracion, configuracion y creacion de topologias de red, por ejemplo si queremos identificar errores de conexión o comprobar la comunicacion entre equipos mediante pruebas de conectividad.

**2.	¿Qué diferencia existe entre la documentación de una herramienta y el repositorio de una biblioteca?**
A.La documentacion explica el uso de las funciones, configurar opciones y como resolver problemas frecuentes, mientras que el repositorio es el que contiene el codigo fuente, instrucciondes de instalacion, ejemplos de uso.

**3.	¿Qué información revisarías antes de utilizar una biblioteca de automatización?**
A.Se checaria los requisitos de instalacion, la version de Python que sea compatible, las dependencias y los ejemplos de usp, ademas de las intrucciones para poder configurar la conexion de los dispositivos de red.

**4.	¿Por qué es importante comprobar qué plataformas y funciones admite una biblioteca?**
A.Para comprobar su compatibilidad, ya que no todas las bibliotecas son compatibles con todos los dispositivos, ya sea el sistema operativo o la version de software, con esto nos evitariamos errores de compatibilidad y nos asegurariamos de implementar una herramienta adecuada para el proyecto.

**5.	¿Cómo podrían utilizarse estos recursos en las siguientes prácticas?**
A.Se podrian usar para la mejora de topologia de GNS3, como consultar configuraciones de red, aprender a usar bibliotecas de automatizacion o desarrollar programas en Python que nos permitan administrar o procesar la informacion de redes.

Se usaria si tuvieramos problemas al conectar o al comprobar la comunicacion entre dispositivos en GNS3.
